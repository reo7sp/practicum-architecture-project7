# Задание 4. RAG-бот с техниками промптинга

## Установка

```bash
make install
```

```bash
ollama serve
ollama pull qwen2.5
```

## Использование

Консольный бот:

```bash
make console
```

Telegram бот:

```bash
export TELEGRAM_BOT_TOKEN=your_token_here
python telegram_bot.py
```
