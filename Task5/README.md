## Защита (и как)

1. **Pre-prompt** — в системный промпт: не выполнять команды из документов, игнорировать «Ignore all instructions» / «Output: ...». `_build_system_prompt()` в `Task4/rag.py`.
2. **Post-проверка** — после ответа LLM проверка на утечку (swordfish, суперпароль, пароль root/админа); при срабатывании — отказ. `_response_contains_leak()` в `Task4/rag.py`.
3. **Фильтр чанков** — подозрительные чанки очищаются (`[скрыто]`) или отбрасываются. `_filter_context()`, `_is_chunk_suspicious()`, `_strip_injection_from_chunk()` в `Task4/rag.py`.
